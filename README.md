# 船舶曲板扫描组件

作者：**江苏科技大学王兴宇（Xingyu Wang）**

本资料用于复现论文。程序采用简化笛卡尔伺服对象，
评价质量反馈、延迟跟踪及在线补偿的互补作用。输出是船厂实测记录，请保密
完整关节力矩控制律的物理验证。


## 第一列编码如何阅读

三位编码从左至右固定为 **Q、D、F**。每一位 **0 表示该组件未启用，1 表示启用**。

| 编码 | Q：质量反馈 | D：延迟跟踪 | F：在线补偿 |
|---|---|---|---|
| 000 | 未启用 | 未启用 | 未启用 |
| 001 | 未启用 | 未启用 | 启用 |
| 010 | 未启用 | 启用 | 未启用 |
| 011 | 未启用 | 启用 | 启用 |
| 100 | 启用 | 未启用 | 未启用 |
| 101 | 启用 | 未启用 | 启用 |
| 110 | 启用 | 启用 | 未启用 |
| 111 | 启用 | 启用 | 启用 |

- **Q**：使用已观测表面质量选择下一观测位置与方向。
- **D**：平滑激活非线性跟踪反馈，并依据误差调节参考轨迹推进速度。
- **F**：采用归一化高斯基函数在线估计扰动，配合权值限幅和泄漏项。

所有组合均保留共同的夹具约束和输入限幅。因此，000 表示关闭这三个被研究的组件，
并不是关闭基础跟踪控制或安全约束。111 表示本任务空间模型中的三个组件全部启用。

## 运行环境与复现步骤

已使用 MATLAB R2023a 实际运行，只需基础 MATLAB，不依赖额外工具箱。

```matlab

verify_ablation
```


只需从现有轨迹重建表格时运行：

```matlab

```



## 工况与共同参数

随机种子为 7301 至 7320。每个配对种子对应五类工况之一，该种子内八种组件组合共享
位置噪声、扰动相位、有效惯量、几何、初始位置与遮挡设置。每类工况包含四个配对种子。

| 工况编号 | 含义与变化 |
|---|---|
| 1 | 名义工况 |
| 2 | 板深增加 18%，扭曲幅值增加 10% |
| 3 | 初始位置偏差为 [0.025, -0.018, 0.020] m |
| 4 | 增加中心 [0.12, 0.42, 0.30] m、半径 0.17 m 的遮挡夹具 |
| 5 | 组合使用工况 2、3、4 的变化 |

名义板长 2.80 m、板宽 1.02 m、板深 0.42 m，离散网格为 72 × 46。
名义扫描距离 0.46 m，观测足迹宽度 0.245 m，距离权重宽度 0.080 m，入射角上限
52°，质量阈值 0.52，夹具安全距离阈值 0.14 m。名义初始位置偏差为
[0.006, -0.005, 0.008] m。有效惯量倍率在 1.10 至 1.25 之间取样。

伺服积分步长 0.02 s，观测更新频率 10 Hz，共同比较窗口 90 s，单次运行上限 180 s，
每个笛卡尔通道的加速度指令上限为 1.2 m/s²。各工况均保持相同质量阈值与输入上限。
完整参数、对象方程、学习规则和参考轨迹可行性处理均在源码中给出。

## 指标定义与解释

- `Coverage90_pct`、`Edge90_pct`：对每个表面样本使用实际观测且通过可见性检测的
  最大单视点质量值，在 90 s 时判断是否达到阈值。此保守判据不同于正文公式（2）的
  概率累计质量状态，不能等同于连续曲面覆盖认证。
- `TrackingRMSE90_mm`：0–90 s 内实际位置相对参考位置的笛卡尔跟踪均方根误差。
  它不是点云重建误差，不能直接与早期名义比较表的重建误差列作数值对比。
- `Time95_s`：首次达到 95% 合格覆盖的观测更新时间。NaN 表示 180 s 内没有达到，
  论文显示为 `>180`，不能按零参与平均。若一组包含未达到目标的运行，不能只取
  成功运行的平均值来代替整组完成时间。
- `Saturation90_pct`：在共同的 0–90 s 等间隔采样窗口内，任一限幅前请求指令严格
  超过输入上限的时刻比例。使用 1e-10 的判断容差，不能从已经限幅的施加输入反推。
- `PeakDemandRatio90`：请求指令无穷范数的峰值与输入上限之比。大于 1 表明存在
  超限请求；小于 1 表明仍有相应归一化输入余量。单次零饱和可以成立，但不是程序预设。
- `MinClearance90_m`：由实际位置与夹具几何直接计算的最小间距，不用人为正下限替换。

配对差值统一定义为“启用后的指标减去关闭后的指标”。误差和饱和率下降较好，覆盖率
上升较好。Q 启用时的 D、F 交互差为 `111 - 110 - 101 + 100`；误差交互差为正表示
边际收益递减，不能描述成已证实的超加性协同优势。
